How detection works

  1. The URL is cleaned up: lower case, no path, international names converted.
  2. The domain comes from the Public Suffix List, so vestnik.svet24.si belongs to svet24.si. A new domain is created with it.
  3. DNS shows where the hostname points.
  4. That address is matched to our servers and to external services such as Cloudflare and Varnish.
  5. Behind an external service the backend can't be seen, so Sextant suggests the server the domain's other sites use. You confirm it.
  6. A first HTTP and certificate probe runs, and redirects are recorded.
Badges: Detected means Sextant is sure, Suggested means please confirm, Not found means you choose.
